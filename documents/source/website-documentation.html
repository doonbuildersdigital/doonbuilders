Overview

01Website at a glance

The Doon Builders website is the corporate site of a three-generation construction and infrastructure company (est. 1968). It presents the company's history, government and private projects, machinery, on-site work and contact options, with a dark/light theme and smooth animation throughout.

Technology

03What the website is built with

The site is written in JavaScript (JSX) with React, bundled by Vite and styled with Tailwind CSS. All libraries are open-source and installed from npm.

PackageVersionUsed for
react, react-dom19.3User-interface library — every page and section is a React component
react-router-dom7.18Page routing (Home, Projects, Contact …) without full page reloads
vite8.3Development server and production build (Rolldown bundler)
@vitejs/plugin-react6.1React / JSX support and fast refresh in Vite
tailwindcss3.4Utility-first CSS framework — all styling, colours, spacing
postcss, autoprefixer8.5 / 10.6CSS processing and browser prefixes
gsap, @gsap/react3.15 / 2.1Animations: hero entrance, scroll reveals, parallax, counters
lenis1.3Smooth scrolling
lucide-react1.49Line icons (arrows, phone, play/pause, menu …)

Tools needed to work on the code

  • Node.js (LTS) with npm — runs the build
  • Git — to clone and push the repository
  • Any code editor (VS Code recommended)

Commands

# install dependencies (first time)
npm install

# run locally at http://localhost:5173
npm run dev

# production build into dist/
npm run build

# preview the production build
npm run preview

# publish a change (Netlify deploys automatically)
git add -A && git commit -m "Describe the change" && git push origin main

  • Page titles and descriptions for Google and social sharing

The enquiry form on the Contact page (/contact) sends every submission to Netlify Forms. Each enquiry is saved in the Netlify dashboard and also emailed to the company.
